#  Embedded C / CAN Communication System

### Automotive ECU Communication and Vehicle Data Monitoring

A software-based automotive CAN communication project developed in **Embedded C** to demonstrate ECU-to-ECU communication, CAN message formatting, vehicle signal transmission and basic vehicle-status monitoring.

> **Project scope:** This repository demonstrates CAN communication concepts through a software simulation/test implementation. It does not claim communication with physical CAN hardware.

##  Project Objectives

The main objectives are:

- Understand automotive CAN communication.
- Define standard CAN message identifiers.
- Create CAN transmit and receive interfaces.
- Encode vehicle signals into CAN data bytes.
- Demonstrate ECU-to-ECU communication.
- Monitor battery voltage, motor speed and temperature.
- Implement basic vehicle-status monitoring.
- Generate a CAN communication test log.
